# GlyphLab

A lightweight editor for the 25×25 Glyph Matrix on Nothing Phone (3).

## Current version

**0.1.0 — Matrix Painter foundation**

- 25×25 square-pixel canvas
- Tap a pixel to toggle it on or off
- Drag to draw
- Clear the canvas
- Monochrome black-and-white interface

## Build

The GitHub Actions workflow builds a debug APK on every push to `main` and on pull requests. You can also start it manually from the Actions tab.

## Planned

- Undo / redo
- Save and load drawings
- Import an image and convert it to 25×25
- Brightness control and preview
- Send a drawing to Glyph Matrix using the official Nothing Glyph Matrix SDK

Animations and frame editing are planned for version 0.2.
